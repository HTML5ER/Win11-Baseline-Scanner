# Win11-Baseline-ScannerМодульный PowerShell-сканер для аудита защищенности операционной системы Windows 11 на соответствие международному стандарту CIS Microsoft Windows 11 Stand-alone Benchmark v5.0.0.Проект спроектирован с упором на отказоустойчивость, независимость от языковой локализации ОС (SID-based идентификация) и изолированное выполнение модулей.🚀 Ключевые особенностиМодульная архитектура: Оркестратор динамически находит и исполняет все скрипты в директории modules/ без хардкода.Изоляция процессов (Sandboxing): Каждый модуль аудита запускается в отдельном дочернем процессе powershell.exe, что предотвращает падение всего сканера при критической ошибке в отдельной проверке.Кросс-локализация: Проверки системных учетных записей завязаны на стандартные Well-Known SIDs (например, -501 для учета Гостя), а не на локализованные имена ("Guest", "Гость").Прямая работа с объектами (Dot Notation): Извлечение параметров реестра выполняется через объекты PowerShell без парсинга текстовых строк.Стандартизированные коды возврата: Модули возвращают строго регламентированные $LASTEXITCODE для интеграции с CI/CD и системами мониторинга.📂 Структура проектаPlaintextWin11-Baseline-Scanner/
